# SysA
SysA is a brutal but high-readable font, which designed for low resolution systems without antialiasing. It contains basic sets of Latin and Cyrillic characters, also numbers and some symbols too.

<img width="1234" height="290" alt="sysa1" src="https://github.com/user-attachments/assets/b8fb2c2c-c027-48b3-873f-bca15b01dc99" />

No diagonals, no curves, only horizontal and vertical lines. It relies on imagination and brain ability to recognize familiar symbols.

The current version of font based on old bitmap one which created by me too. At this time only bold weight is available 'cause it's kind of challenge, but in the future a regular variant may come out too. 
There is no kerning nor ligatures either, and a lot of work needs to be done for MVP.

The font development goes in FontForge, the Em-size is 16, and it saved as dir (*.sfdir).

Feel free to suggest your ideas.
